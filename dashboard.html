DSA Concepts & Interview Prep
Greedy Algorithm
O(N log N) · EDF + Priority
  • Makes locally optimal choice at each step
  • Sort by deadline then priority (heap)
  • Respects dependency topological order
  • Fast: no backtracking needed
  • Used in: CPU scheduling, job shops
Priority Queue
O(log N) insert/extract · Min-Heap
  • Binary min-heap for task selection
  • Score = deadline / (priority × profit)
  • O(log N) push/pop operations
  • Always picks best next task instantly
  • Used in: Dijkstra, OS task queues
Dynamic Programming
O(N²) · Weighted Job Scheduling
  • Solves subproblems, stores solutions
  • Binary search for O(N log N) variant
  • Optimal non-overlapping job subset
  • Maximizes total profit globally
  • Used in: genome sequencing, finance
Topological Sort
O(V+E) · Kahn's Algorithm
  • BFS-based dependency resolution
  • Detects circular dependencies
  • Ensures dep tasks run first
  • DAG traversal using in-degree
  • Used in: build systems, makefiles
Data Structures
Core DSA Used
  • Min-Heap (heapq) — priority queue
  • Hash Map (dict) — O(1) task lookup
  • Adjacency List — dependency graph
  • Deque — BFS queue for topo-sort
  • Sorted Array — DP binary search

🎯 "Explain Your Project" — Model Answer

"I built a Task Scheduler Optimization System that solves the problem of executing multiple tasks efficiently when each has different priorities, deadlines, execution times, and dependency constraints. The system implements three algorithms: a Greedy scheduler using topological sort + EDF, a Priority Queue scheduler using Python's min-heap with profit-weighted scoring, and a Dynamic Programming solver for the Weighted Job Scheduling Problem. Each algorithm produces an optimized execution plan, calculates KPIs like on-time percentage and total profit, and identifies missed or late tasks. The system also includes a what-if analysis feature to test constraint changes in real time. This mirrors how real-world systems like OS CPU schedulers, cloud job queues, and project management tools work."
